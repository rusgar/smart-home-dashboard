# 🏠 Smart Home Dashboard

Simulador educativo de consumo doméstico con dashboard interactivo tipo Home Assistant. Permite a los alumnos encender electrodomésticos, simular un día completo de 24 horas y exportar los datos a CSV/Excel para su análisis.

---

## 📋 Descripción

Este proyecto simula el consumo **eléctrico**, **hídrico** y **térmico/gas** de una vivienda a lo largo de 24 horas. Los usuarios pueden:

- Encender/apagar **electrodomésticos** (lavadora, horno, aire acondicionado, ducha, etc.) durante el tiempo que quieran.
- Ver en tiempo real el impacto de cada aparato en el consumo.
- Observar **gráficas comparativas** hora a hora (potencia activa/reactiva, factor de potencia, agua, gas).
- **Exportar** los datos a CSV o Excel para trabajar con tablas dinámicas y gráficos.
